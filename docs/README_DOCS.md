## 🗂️ Documentation Standards

When creating new documentation:

1. **Place in appropriate subdirectory** - Use existing categories
2. **Use Markdown** - `.md` format with proper headers
3. **Link related docs** - Cross-reference extensively
4. **Update this index** - Keep README_DOCS.md current
5. **Keep it current** - Archive outdated docs to `archive/`

Found a mistake? Want to improve documentation?
